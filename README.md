# Chromatic aberration mod

Fabric 客户端模组：从玩家视角渲染色差（chromatic aberration）后处理效果。默认强度随相机移动速度变化——移动越快，红蓝分离越明显；也可以在配置中固定强度。

## 兼容性

| | |
| --- | --- |
| Minecraft | 1.20.1 |
| Fabric Loader | 0.15.0 或更高 |
| Fabric API | 必需 |
| Mod Menu | 可选（配置界面） |
| Java | 17 或更高 |

## 特性

- **随速度变化**——超过步行速度后逐渐出现，移动越快效果越强，过渡平滑。
- **中心保持清晰**——屏幕中间不处理色差，越靠近边缘逐渐增强，准星区域仍然清晰。
- **固定强度模式**——完全忽略相机速度，只由滑杆决定强度。
- **静止基线**——可选在静止时保留 35% 的效果。
- **玩家状态触发**——默认所有状态都应用；关闭后可按移动、姿态、骑乘和环境条件筛选，选中多个条件时任意一个生效即可触发。
- **兼容 Iris 光影**——检测到光影包启用时自动让出画面，关闭光影后自动恢复。
- **静止零开销**——强度接近 0 时完全不渲染。

## 配置

安装 Mod Menu 后可从模组列表打开配置；未安装 Mod Menu 也能正常运行。配置保存在 `config/chromaticaberration.json`。

| 选项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| 色差强度 | 滑杆 0–200% | 100% | 强度倍率，实时生效。 |
| 禁用中心安全区 | 开关 | 关 | 整屏都渲染色差，包括准星区域。 |
| 静止时也渲染 | 开关 | 关 | 不移动时保留 35% 的基线强度。 |
| 禁用速度影响 | 开关 | 关 | 只用滑杆控制强度，忽略相机速度。 |
| 全部状态 | 开关 | 开 | 开启时不筛选玩家状态；关闭后可编辑下面四组条件。 |
| 移动状态 | 多选 | 空 | 行走、疾跑、潜行、爬行、跳跃、下落、游泳、水下移动、漂浮、鞘翅、飞行、攀爬等。 |
| 姿态状态 | 多选 | 空 | 站立、潜行、游泳、鞘翅、睡觉和激流旋转攻击。 |
| 骑乘状态 | 多选 | 空 | 马、猪、炽足兽、船、矿车、骆驼和其他实体。 |
| 环境状态 | 多选 | 空 | 水下、熔岩、反胃、夜视、水下呼吸、受到伤害和视角摇晃。 |

条件采用“或”逻辑：例如同时选择“疾跑”和“水下”，两种情况分别出现时都会应用色差。关闭“全部状态”但没有选择任何条件时不会应用色差。

## 安装

1. 为 Minecraft 1.20.1 安装 Fabric Loader。
2. 将 Fabric API 放入 `mods/`；Mod Menu 可选，但打开配置界面需要它。
3. 将本模组 jar 放入 `mods/`。
4. 先删除旧版本的本模组——两个 Mod ID 相同的 jar 会导致 Fabric 无法启动。

## 构建

每个分支都是完整的 Gradle 工程，并自带 wrapper。

```bash
./gradlew build        # Linux / macOS
gradlew.bat build      # Windows
```

产物输出到 `build/libs/`。

本版本产物名为：

```text
chromatic-aberration-mod-beta1.2.0+mc1.20.1.jar
```

## Iris 与光影包

通过 Iris API 检测光影包。光影启用时本模组不会碰最终画面，既不会叠加出双倍效果，也不会和光影抢 framebuffer；关闭光影后自动恢复。

## 调试按键

按 <kbd>F8</kbd> 循环切换着色器调试模式：正常、直通复制、强制不透明 alpha、alpha 可视化。反馈渲染问题时很有用。
